# WOWSHOPPING V9

Static storefront + admin panel.

## Included upgrades
- Unlimited home banner carousel with autoplay, previous/next controls, dots and drag-to-reorder in Admin.
- One banner container instead of separate banner blocks.
- Banner desktop/mobile images, upload, text, button, URL, visibility and category controls.
- Search uses the existing header search field; no second search input appears when searching.
- Product cards show polished Best Seller / New / Discount badges and savings.
- Product detail pages keep the same professional badge treatment.
- Footer simplified around the Stay In The Loop newsletter and configurable Follow Us social links.
- Social platforms can be added, edited, linked and hidden from Admin.
- Customer Care page title/intro/FAQ heading and company/policy page text are editable from Admin.
- Existing product, category, theme, branding, menu and shipping controls remain available.
- Data is shared between `index.html` and `admin.html` through browser localStorage key `wow_admin_data_v4`.

## Run
Open `index.html` for the storefront and `admin.html` for the admin panel.
