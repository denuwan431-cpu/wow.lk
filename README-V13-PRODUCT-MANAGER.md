# WOWSHOPPING V13 — Universal Product Manager

The Admin > Product Manager now supports one unified product workflow for:
- Kids, Men, Women, Unisex and Accessories
- Clothing, Shoes, Caps & Hats, Bags, Jewellery, Watches and other product types
- Optional sizes for apparel/shoes
- Optional colors for any product
- Optional variant stock JSON for color/size combinations or color-only products
- Brand, material/specification, tags, highlights, images, pricing, sale pricing and stock
- New arrival / Best seller / visibility controls

Examples:
- T-shirt: Department=Men, Type=Clothing, Sizes=S,M,L,XL, Colors=Black,White
- Shoes: Department=Women, Type=Shoes, Sizes=37,38,39,40, Colors=Black,White
- Watch: Department=Accessories, Type=Watches, Sizes empty, Colors=Silver,Gold
- Jewellery: Department=Accessories, Type=Jewellery, Sizes empty, Colors=Gold,Silver
